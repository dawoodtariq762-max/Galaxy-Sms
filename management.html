How this works

The panel never calls a provider directly. This screen only stores settings in the database; the background sync service reads them automatically and writes SMS into the local database.
Sync interval is per provider (recommended 10–15 seconds). Records per sync defaults to 50. Changes apply on the next cycle — no restart and no file editing required.

How this works

SMPP is an additional channel. It runs alongside the HTTP callback and the API Providers sync — all three write into the same SMS records, and none of them affect the others.
Client mode — Galaxy SMS connects out to your provider's SMPP server. You need their host, port, system ID and password.
Server mode — Galaxy SMS listens on a port and your carrier connects in. You choose the system ID and password and give them to the carrier, plus this server's IP and the port.
Reconnection is automatic with backoff. Incoming messages are de-duplicated, so a redelivered message is never counted twice.
